# Земеров Владимир Ит3 Лабораторная №1

## Задание 1

### Задача 1.1. Дробная часть

**Требуется:** отделить от числа дробную часть и вернуть её.

Необходимо реализовать метод таким образом, чтобы он возвращал только дробную часть числа x. Вещественное число можно преобразовать к целому, отбросив дробную часть.

Пример: x = 5,25, результат: 0,25.

**Алгоритм решения:**

1. В отдельном классе создаём метод zadach1\_1.
2. Создаём переменную типа int.
3. Записываем в неё число x, преобразованное в целое.
4. Из исходного числа вычитаем целую часть.
5. Возвращаем полученный результат.

### Задача 1.2. Сумма знаков

**Требуется:** найти сумму двух последних цифр числа.

Необходимо реализовать метод таким образом, чтобы он возвращал результат сложения двух последних знаков числа. В числе должно быть не менее двух знаков.

Пример: x = 4568, результат: 14.

**Алгоритм решения:**

1. Создаём метод zadach1\_2.
2. С помощью остатка от деления на 10 получаем последнюю цифру числа.
3. С помощью деления на 10 убираем последнюю цифру.
4. У оставшегося числа снова получаем последнюю цифру.
5. Складываем найденные цифры.
6. Возвращаем результат.

### Задача 1.6. Большая буква

**Требуется:** проверить, является ли символ заглавной английской буквой.

Необходимо реализовать метод таким образом, чтобы он возвращал true, если символ является большой буквой в диапазоне от A до Z, и false в остальных случаях.

Пример: x = D, результат: true.

**Алгоритм решения:**

### Задача 1.7. Диапазон

**Требуется:** проверить, входит ли число в заданный диапазон.

Метод принимает левую и правую границу диапазона. Необходимо вернуть true, если число num входит в диапазон вместе с границами. Заранее неизвестно, какая граница больше.

Пример: a = 5, b = 1, num = 3, результат: true.

**Алгоритм решения:**

1. Создаём метод zadach1\_7.
2. Сравниваем значения a и b.
3. Если a больше b, меняем их местами.
4. Проверяем, находится ли num между границами.
5. Возвращаем результат проверки.

### Задача 1.10. Многократный вызов

**Требуется:** складывать последние цифры двух чисел и использовать метод несколько раз подряд.

Необходимо реализовать метод, который складывает цифры двух чисел из разряда единиц. С его помощью нужно последовательно сложить пять чисел и вывести результат.

Пример: 5 + 11 = 6, затем 6 + 123 = 9, затем 9 + 14 = 13, затем 13 + 1 = 4.

**Алгоритм решения:**

1. Создаём метод zadach1\_10.
2. Получаем последнюю цифру первого числа.
3. Получаем последнюю цифру второго числа.
4. Складываем эти цифры.
5. Полученный результат передаём в следующий вызов метода.
6. Повторяем действия для остальных чисел.

## Задание 2

### Задача 2.1. Модуль числа

**Требуется:** вернуть число без знака минус.

Необходимо реализовать метод таким образом, чтобы он возвращал модуль числа x. Положительное число должно остаться без изменений, а из отрицательного числа нужно убрать знак минус.

Пример: x = -3, результат: 3.

**Алгоритм решения:**

1. Создаём метод zadach2\_1.
2. Проверяем, является ли число отрицательным.
3. Если число отрицательное, меняем его знак.
4. Если число положительное, возвращаем его без изменений.

### Задача 2.4. Строка сравнения

**Требуется:** сравнить два числа и вернуть строку с правильным знаком.

Необходимо вернуть строку, содержащую два числа и знак сравнения: больше, меньше или равно.

Пример: x = 5, y = 7, результат: 5<7.

**Алгоритм решения:**

1. Создаём метод zadach2\_4.
2. Сравниваем числа x и y.
3. Если x меньше y, используем знак <.
4. Если x больше y, используем знак >.
5. Если числа равны, используем знак ==.
6. Возвращаем полученную строку.

### Задача 2.5. Тройной максимум

**Требуется:** найти максимальное из трёх чисел.

Необходимо реализовать метод таким образом, чтобы он возвращал максимальное из трёх переданных чисел.

Пример: x = 5, y = 7, z = 7, результат: 7.

**Алгоритм решения:**

1. Создаём переменную и записываем в неё первое число.
2. Сравниваем его со вторым числом.
3. Если второе число больше, записываем его как максимальное.
4. Сравниваем найденный максимум с третьим числом.
5. Возвращаем максимальное значение.

### Задача 2.8. Возраст

**Требуется:** правильно написать слово после числа: год, года или лет.

Необходимо вернуть строку, в которой сначала записано число, а затем правильное окончание. Слово год используется для чисел, заканчивающихся на 1, кроме 11. Слово года используется для чисел, заканчивающихся на 2, 3 или 4, кроме 12, 13 и 14. Во всех остальных случаях используется слово лет.

Пример: 44 года.

**Алгоритм решения:**

1. Создаём метод zadach2\_8.
2. Получаем последние две цифры числа.
3. Отдельно проверяем числа от 11 до 14.
4. Получаем последнюю цифру числа.
5. Проверяем окончание числа.
6. Выбираем подходящее слово.
7. Объединяем число со словом.

### Задача 2.9. День недели

**Требуется:** по номеру определить день недели.

Метод принимает число от 1 до 7. Число 1 означает понедельник, а число 7 — воскресенье. Если число не входит в диапазон от 1 до 7, необходимо вернуть текст это не день недели. В задаче нужно использовать switch.

**Алгоритм решения:**

1. Создаём метод zadach2\_9.
2. Передаём число в оператор switch.
3. Для каждого числа от 1 до 7 указываем свой день недели.
4. Если число другое, используем вариант default.
5. Возвращаем соответствующий текст.
