# Земеров Владимир Ит3 Лабораторная №2

## Задание 1

### Задача 1.1. Точка координат

**Требуется:** создать сущность Точка на двумерной плоскости

Необходимо создать класс, который описывает точку на плоскости с координатами X и Y. Точка должна уметь возвращать своё текстовое представление в виде {X;Y}

Пример: точка с координатами 1 и 2 должна вывести {1;2}

**Алгоритм решения:**

1. Создаём класс Point
2. Создаём два свойства x и y типа int
3. Создаём конструктор, который принимает координаты и записывает их в свойства
4. Создаём метод toString, который возвращает строку в формате {X;Y}
5. В main создаём три точки с разными координатами
6. Выводим их текстовое представление на экран

### Задача 1.3. Имена

**Требуется:** создать сущность Имя с тремя параметрами

Необходимо создать класс, который описывает имя человека через фамилию, личное имя и отчество. Имя должно уметь возвращать строку в формате Фамилия Имя Отчество. Если какой-то параметр не задан, он не должен участвовать в формировании строки

Пример: Клеопатра, Пушкин Александр Сергеевич, Маяковский Владимир

**Алгоритм решения:**

1. Создаём класс Name
2. Создаём три свойства типа String для фамилии, имени и отчества
3. Создаём конструктор, который принимает три параметра
4. Создаём метод toString, который собирает строку из заданных параметров
5. Проверяем каждый параметр на null
6. Если параметр задан, добавляем его в строку через пробел
7. Возвращаем получившуюся строку
8. В main создаём три имени с разными наборами параметров и выводим их

## Задание 2

### Задача 2.1. Прямая

**Требуется:** создать сущность Линия на двумерной плоскости

Необходимо создать класс, который описывает линию через две точки: начало и конец. Линия должна уметь возвращать текстовое представление в формате Линия от{X1;Y1} до{X2;Y2}. Для координат нужно использовать класс Point из задачи 1.1

**Алгоритм решения:**

1. Создаём класс Line
2. Создаём два свойства типа Point для начала и конца линии
3. Создаём конструктор, который принимает две точки
4. Создаём метод toString, который возвращает строку в нужном формате
5. В main создаём три линии
6. Линия 3 использует те же объекты Point, что и линии 1 и 2
7. Изменяем координаты точек линий 1 и 2, чтобы линия 3 тоже изменилась
8. Затем заменяем точки линии 1 на новые объекты, чтобы линия 3 не изменилась

## Задание 3

### Задача 3.3. Города

**Требуется:** создать сущность Город с путями к другим городам

Необходимо создать класс, который описывает город с названием и набором путей к другим городам. Каждый путь содержит город назначения и стоимость поездки. Город должен уметь возвращать текстовое представление в формате название: список городов со стоимостью

**Алгоритм решения:**

1. Создаём класс City
2. Создаём свойство name типа String для названия города
3. Создаём два списка: список городов и список стоимостей
4. Создаём конструктор, который принимает только название
5. Создаём второй конструктор, который принимает название и массивы городов и стоимостей
6. Создаём метод addRoad, который добавляет город и стоимость в списки
7. Создаём метод toString, который выводит название города и все связанные города со стоимостями
8. В main создаём города A, B, C, D, E, F и добавляем дороги согласно рисунку

## Задание 4

### Задача 4.8. Создаем Города

**Требуется:** расширить сущность Город двумя способами создания

Необходимо добавить возможность создавать город двумя способами: только по названию или по названию вместе с набором связанных городов и стоимостями путей

**Алгоритм решения:**

1. В классе City уже есть конструктор, который принимает только название
2. Добавляем второй конструктор, который принимает название, массив городов и массив стоимостей
3. Внутри второго конструктора проходим по массивам и добавляем каждый город и стоимость в списки
4. В main создаём город только по названию
5. Создаём второй город с названием и набором путей
6. Выводим оба города на экран

## Задание 5

### Задача 5.5. Дроби

**Требуется:** создать сущность Дробь с операциями

Необходимо создать класс, который описывает дробь с числителем и знаменателем. Дробь должна уметь складываться, вычитаться, умножаться и делиться на другую дробь или целое число. Результатом каждой операции должна быть новая дробь, исходные дроби не должны изменяться

**Алгоритм решения:**

1. Создаём класс Fraction
2. Создаём два свойства типа int для числителя и знаменателя
3. Создаём конструктор, который принимает числитель и знаменатель
4. Создаём метод toString, который возвращает строку в формате числитель/знаменатель
5. Создаём метод sum для сложения с другой дробью
6. Создаём метод sum для сложения с целым числом
7. Создаём метод minus для вычитания другой дроби
8. Создаём метод minus для вычитания целого числа
9. Создаём метод mult для умножения на другую дробь
10. Создаём метод mult для умножения на целое число
11. Создаём метод div для деления на другую дробь
12. Создаём метод div для деления на целое число
13. В каждом методе создаём новую дробь с результатом и возвращаем её
14. В main создаём три дроби и выводим примеры всех операций
15. Выполняем цепочку f1.sum(f2).div(f3).minus(5) и выводим результат

## Проверка ввода

В лабораторной работе 2 ввод с клавиатуры не используется, все данные заданы в коде. Поэтому проверка ввода не требуется.

## Оформление

Все классы находятся в одном проекте, но каждый класс описан отдельно. В главном методе main показана работа всех классов и методов. Для каждого класса созданы свойства, конструкторы и метод toString.
